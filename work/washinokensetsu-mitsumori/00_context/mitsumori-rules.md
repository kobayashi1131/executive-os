# 見積の作り方ルール（小林指定）

職人・業者の見積からわしの建設の見積書を作るときのルール。このチャットで見積を作るときも、アプリの初期設定も、これに従う。

更新: 2026-10-07（小林の指示）

## 金額

| 項目 | ルール |
|---|---|
| 原価 | 職人・業者の **NET金額**（実際に払う額）。定価ではない |
| 売値 | 原価 × **1.5**（100円単位で切り上げ）。単価がある行は職人の単価×1.5（10円単位で切り上げ） |
| 数量 | **小数は切り上げ**（56.4m → 57m）。単価はそのままなので売値は増える。原価は職人見積のまま |
| わしのの人 | 品名は **「現場管理費」**、数量・単位は **1式**（人工では書かない） |
| わしのの人の金額 | **原価も売値も 1人1日 25,000円**（半日は12,500円）。原価にも必ず入れる |
| 諸経費 | 明細の合計 × **8%**（原価は業者側の諸経費・出張費があればそれ） |
| 値引き | 最後に入れて、**粗利率25%超え**かつキリのいい額に着地させる |

## 書き方（原紙への書き込み）

| 項目 | ルール |
|---|---|
| 原価 | G列（印刷範囲外）に金額 |
| 職人名 | 原価の横（**H列**）に職人・業者名。わしのの人の分は「わしの建設（名前・日数）」 |
| 値引き | 品名は **「値引き」**。**最後の明細から3行下**に、品名を**中央揃え**で書く |
| 注意書き | 「※平日工事となります。」など業者見積の条件は、**値引きの1行下**に**左寄せ**で書く |
| 工事名 | 明細の1行目（8行目）。作業日があれば備考欄に「10/18，19」の形で |
| ファイル名 | 工事名＋年月（例: 東海工場シートシャッター修理2610.xlsx） |
| 保存先 | `work/washinokensetsu-mitsumori/06_data/mitsumori/`（gitに上げない） |

## 確認すること

- 売値がメーカー定価を超える場合は、小林に一言伝える（判断は小林）

## アプリでの扱い（2026-10-07）

- アプリ（04_system/app/index.html）の初期設定はこのルール（×1.5、諸経費8%、1日25,000円、粗利25%、値引き後は1万円単位）
- 読み取りは課金なし: スマホのClaudeアプリに見積を渡し、アプリの「頼み方をコピー」の文で読ませ、返ってきたJSONをアプリに貼って取り込む
- NET金額があれば各行の原価をその割合で割り振る。業者の諸経費・出張費は諸経費の原価へ
- 「頼み方」の本文は index.html の `AI_PROMPT`
