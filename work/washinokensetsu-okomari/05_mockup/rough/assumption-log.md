# 仮置き・未確認ログ

| 項目 | ラフモックでの仮置き | 確認先 |
|---|---|---|
| 社長直送の方法 | メールで社長に直接届く（わしの建設のリストには中身を残さない） | 実装判断時。社長がメールを見るか要確認 |
| 社長直送の用紙 | 封筒のまま社長へ渡し、件数だけ手入力 | 小林 |
| 「社長だけに見せる」チェック | どの分類でも選べる | 小林 |
| 写真 | 付けられる（モックでは保存しない） | 実装判断時 |
| 報告に載せる範囲 | 「対応しました」以外の、中身が見える分 | 小林 |
| 社長本人への不満・ハラスメント | 未設計 | 小林・社長と相談 |
| 悪口の扱い | 未設計（提案資料では「そのままの形ではお届けしない」） | 小林 |
| お客さん名 | 架空の「サンプル工業」 | 最初のお客さんが決まったら |
| 作り方 | 未定（Googleフォーム＋スプレッドシート案が有力） | 実装判断 |
| 費用 | 未定 | 小林 |
