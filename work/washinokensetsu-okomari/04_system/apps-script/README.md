# お困りごとポスト 社内テスト版（Google Apps Script）

わしの建設の社内で、スマホからの入力だけを試すための版。小林のGoogleアカウントで動かす。

## できること

- QRコード → スマホで入力 → 受付番号（S-0001〜）が出る
- 建物系の声: スプレッドシート「受付」シートに中身ごと記録（＝わしの建設のリスト）。写真はGoogleドライブの「お困りごとポスト_写真」フォルダに保存
- 人間関係・お給料／「社長だけに見せる」: 中身は社長にメールで送り、シートには番号と分類だけ
- メニュー「お困りごとポスト」→「受け付けました」を全部「社長に届けました」に切り替え

## テストでの注意

- メールは小林のGmailから送られるので、中身が小林の「送信済み」に残る。テスト中は、人間関係・お給料は**練習用の内容**で書いてもらう（画面にも表示済み）
- 本番（お客さん向け）では、この点を解決してから使う

## 準備の手順（30分くらい）

1. Googleドライブで、新しいスプレッドシートを作る。名前は「お困りごとポスト（社内テスト）」
2. メニュー「拡張機能」→「Apps Script」を開く
3. 最初からある `コード.gs` の中身を全部消して、このフォルダの `Code.gs` の中身を貼り付ける
4. 左の「＋」→「HTML」で、名前を `Index` にしてファイルを作り、`Index.html` の中身を貼り付ける
5. 保存（フロッピーのマーク）
6. 上の関数の選択で `setup` を選んで「実行」
   - 「承認が必要です」→ 小林のアカウントを選ぶ →「このアプリは Google で確認されていません」と出たら「詳細」→「（安全ではないページ）に移動」→「許可」
   - 自分で作ったプログラムなので、この警告は出て当たり前
7. スプレッドシートに戻り、「お客さん」シートの C2 に、テストで社長役になる人のメールアドレスを入れる
8. Apps Script の画面で「デプロイ」→「新しいデプロイ」
   - 種類: ウェブアプリ
   - 次のユーザーとして実行: 自分
   - アクセスできるユーザー: 全員
   - 「デプロイ」→ 出てきた「ウェブアプリのURL」をコピー
9. QRコードを作る: パソコンのChromeでそのURLを開き、アドレスバーの右の共有マーク →「QRコードを作成」→ ダウンロードして印刷

## 動作確認

- 自分のスマホでQRを読み、建物・設備で1件送る → 受付番号が出る → 「受付」シートに1行増える
- 人間関係で1件送る（練習用の内容）→ 社長役にメールが届く → シートには「（社長に直送）」とだけ出る
- 名前なしで建物・設備を送ろうとすると止まる

## 直した後

`Code.gs` や `Index.html` を直したら、「デプロイ」→「デプロイを管理」→ 鉛筆マーク → バージョン「新バージョン」→「デプロイ」。URLは変わらない。
