# 大阪ビンゴ合戦 本番アプリ デプロイ手順（詳細版）

わしの建設のアプリと同じ方式（フロントはCloudflare Pages、データ保存はGoogle Apps Script）。Claudeアカウント不要で、誰でもURLを開くだけで使える。

コードは書かなくていい。ブラウザでの画面操作だけ。詰まったらそのままIA子に「〇番の△△が出ない」と聞けばOK。

## 全体像

```text
みんなのスマホ (index.html を開く)
        │  4秒おきに読み書き
        ▼
Google Apps Script (Code.gs をWebアプリとして公開)
        │  保存先
        ▼
スクリプトプロパティ（ゲーム状態のJSONを1つだけ保存）
```

- `index.html`：見た目と操作。Cloudflare Pagesで公開する（GitHub経由）。
- `Code.gs`：データの保存・読み出しだけを行う最小限のバックエンド。Googleアカウントで動かす。

やることは大きく4つ。**手順2（GAS_URLの書き込み）はIA子が代わりにやる**ので、小林がブラウザで触るのは実質手順1・3・4だけ。

## 手順1: Google Apps Script をデプロイする

### 1-1. プロジェクトを作る

1. ブラウザで `script.google.com` を開く（普段使っているGoogleアカウントでログインした状態で）。
2. 画面左上あたりの「**+ 新しいプロジェクト**」をクリック。
3. エディタ画面が開く。中央に `function myFunction() {\n\n}` のようなコードが最初から入っている。

### 1-2. コードを貼り替える

4. エディタの中身をクリックしてから `Ctrl+A`（全選択）→ `Delete`（全部消す）。
5. `work/bingo-app/04_system/app/Code.gs` の中身を全部この会話でIA子に見せてもらう（またはファイルを直接開いてコピー）→ 空になったエディタに貼り付け（`Ctrl+V`）。
6. 左上の「無題のプロジェクト」という文字をクリックして、名前を「bingo-app-backend」などに変更（任意。しなくても動く）。
7. `Ctrl+S`（または上部のフロッピーアイコン）で保存。

### 1-3. Webアプリとして公開する

8. 画面右上の青い「**デプロイ**」ボタン → 「**新しいデプロイ**」をクリック。
9. 「デプロイタイプの選択」という小さいダイアログが出る。左側の歯車アイコン⚙️をクリック → 出てきた一覧から「**ウェブアプリ**」を選ぶ。
10. 設定項目が下に出てくる。
    - 説明: 空欄でOK（気になるなら「v1」とでも）
    - 次のユーザーとして実行: 「**自分**」のまま変更しない
    - アクセスできるユーザー: プルダウンをクリックして「**全員**」に変更 ← ここが一番大事。これでClaudeアカウントなしの友達もアクセスできる
11. 「**デプロイ**」をクリック。

### 1-4. 初回の承認画面（1回だけ出る）

12. 「承認が必要です」という画面が出る → 「**アクセスを承認**」。
13. 自分のGoogleアカウントを選ぶ画面が出る → 自分のアカウントをクリック。
14. 「このアプリは Google で確認されていません」という警告画面が出ることがある（自分で作ったスクリプトだから出る、正常）。
    → 左下の「**詳細**」をクリック → 出てきた「bingo-app-backend（安全ではないページ）に移動」をクリック。
15. 権限の確認画面が出る → 「**許可**」をクリック。

### 1-5. URLをコピーする

16. デプロイが完了すると「デプロイが更新されました」の画面に「ウェブアプリ」という項目とURLが表示される。
    形は `https://script.google.com/macros/s/AKfycb.../exec` のような長い文字列。
17. そのURLをコピーして、**この会話にそのまま貼って**教えてください。IA子が `index.html` に書き込んでcommitします（手順2は不要）。

**後で `Code.gs` を修正したくなったら:** エディタで直して保存 →「デプロイ」→「デプロイを管理」→ 既存デプロイの鉛筆アイコンで編集 →「バージョン」を「新バージョン」に変更 →「デプロイ」。これをしないと修正が反映されない。

## 手順3: GitHubにアップロードする

すでに `kobayashi1131` のGitHubアカウントを持っているので、それを使う。

1. `github.com` にログイン。
2. 右上の「**+**」アイコン →「**New repository**」。
3. Repository name に `bingo-app` などと入力。
4. Public / Private の選択は「**Private**」推奨（友達限定の遊びなので）。
5. 一番下の「**Create repository**」をクリック。
6. 作成直後の画面に出てくる「**uploading an existing file**」というリンクをクリック
   （見当たらなければ「Add file」ボタン →「Upload files」）。
7. IA子が書き換え済みの `index.html`（手順2完了後のもの）を、画面の点線エリアにドラッグ＆ドロップ
   （またはクリックしてファイル選択）。
8. 画面下の方にある緑の「**Commit changes**」ボタンをクリック。

## 手順4: Cloudflare Pages に接続する

1. `dash.cloudflare.com` にログイン。
2. 左側メニューの「**Workers & Pages**」をクリック。
3. 右上あたりの「**Create application**」（作成）ボタン → 上部タブで「**Pages**」を選択。
4. 「**Connect to Git**」（Gitに接続）をクリック。
5. 初回はGitHubとの連携画面が出る → GitHubアカウントを選び、対象リポジトリとして先ほど作った `bingo-app` を選択して許可
   （「All repositories」を許可してもよいし、「Only select repositories」で `bingo-app` だけ選んでもよい）。
6. 連携できたら `bingo-app` リポジトリを選んで「**Begin setup**」。
7. 「Set up builds and deployments」という画面が出る。
   - Framework preset: **None** のまま
   - Build command: **空欄のまま**
   - Build output directory: **空欄のまま**（もし必須になっていたら `/` とだけ入力）
8. 「**Save and Deploy**」をクリック。
9. 30秒〜1分ほどでデプロイ完了。「Success」の画面に、発行されたURL
   （例: `https://bingo-app-xyz.pages.dev`）が表示される。これが友達に共有する本番URL。

## 既知の制約

- データの保存先（スクリプトプロパティ）は容量が小さいので、写真は保存しない設計にしてある（達成報告はLINEで）。
- 複数人が同時に同じ内容を編集すると、最後に保存した内容が勝つ（後勝ち）。取り合いになるほど頻繁な同時編集は想定していない。
- 自動更新は4秒間隔。リアルタイムではなく「ほぼリアルタイム」。
