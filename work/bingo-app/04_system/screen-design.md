# 画面設計: bingo-app（本番版 `04_system/app/index.html`）

`01_business/game-design.md` の仕様を元にした画面一覧・機能一覧。GAS+Cloudflareで実装済みの本番版に対応。旧・ラフモック（`04_system/mockup/`）や旧・1画面版（`04_system/app/index.single-page.html`）とは構成が異なる。

## 画面一覧・遷移

```text
S1 表紙(チーム選択＋名前入力。端末ごとにlocalStorageで記憶)
  ↓
S2 カード設定画面(項目プール管理＋チームA/Bのカード作成)
  ↓（誰か1人が「ゲーム開始」を押す＝全員の画面が自動でS3に切り替わる）
S3 ゲーム中画面(スコア・タイマー、ビンゴマス、追加ミッション、共通ミッション、面白出来事)
  ├→ タイマー停止／再開
  ├→ ゲーム中断（即座に終了扱いにする）
  └→ 完全リセット（confirm後、全データを初期化してS2へ）
  ↓（時間切れ or 中断で「結果発表」ボタンが出現→タップ）
S4 結果画面(最終スコア・勝敗・晩飯おごり演出)
  └→ 完全リセットもここから可能
```

- 画面遷移はゲーム全体の進行状況（`state.phase`: setup/playing/ended）に全員が追従する。誰かが開始・中断・リセットすると、他の全員の画面も自動で切り替わる。
- 「結果発表」だけは各自のタップで個別に見る（強制的には切り替わらない）。

## 画面ごとの内容

### S1 表紙
- 表示: チーム選択（A/B）、名前入力
- 操作: 「次へ」→ localStorageに保存し、参加者名簿（`state.roster`）に追加。以後この端末では自動スキップされる
- 「チーム・名前を変更する」リンクでいつでも再度表示可能

### S2 カード設定画面
- 表示: 項目プール一覧、チームA/Bのカード（5×5グリッド、中央固定=パチンコ初当たり0pt）、各チームの参加者名簿
- 操作: 項目プールの追加・編集・削除（全員可）。空きマスをタップ→項目プールから選んで配置。「ランダムで配置する」で自動抽選配置
- 「ゲーム開始」ボタンで S3 へ（6時間タイマー起動、全員の画面が自動遷移）

### S3 ゲーム中画面
- 表示: スコアボード（チームA/B合計点・ビンゴ数）、残り時間、両チームのビンゴマス、追加ミッション（旧・強制ミッション）、共通ミッション、面白出来事（自由メモ）
- 操作: マスをタップ→達成/未達成をトグル（写真提出は廃止。達成報告はLINEで行う運用）
- 操作: 追加ミッションを項目プールから選んで送信（各チーム2回まで）。ビンゴマスと同一内容なら達成時に対応マスも自動開放
- 操作: 共通ミッションはチェックボックスで両チーム独立に達成可（各2pt）
- 操作: 面白出来事は自由記入のテキストメモ（写真はLINEで共有）
- 操作: タイマー停止／再開（一時停止中は残り時間が止まる）
- 操作: ゲーム中断（即座に終了扱いにして「結果発表」ボタンを出す）
- 操作: 完全リセット（confirm後、全データ初期化してS2へ戻る。新しいゲームをやり直せる）
- 時間切れ、または中断すると「結果発表」ボタンが出現

### S4 結果画面
- 表示: 最終スコア、勝敗（または引き分け）、晩飯おごり演出
- 操作: 「ゲーム画面に戻る」でS3へ。完全リセットもここから可能
- 未確認: 同点時の勝敗判定（現状は引き分け扱い）

## 機能一覧

| 機能ID | 機能名 | 概要 |
|---|---|---|
| F1 | 参加登録 | チーム・名前をlocalStorageに保存、共有の参加者名簿に追加 |
| F2 | 項目プールCRUD | ミッション項目の追加・編集・削除（全員可） |
| F3 | カード作成 | 項目選択＋グリッド自由配置、ランダム配置 |
| F4 | ゲーム進行管理 | setup/playing/endedのフェーズを全員で共有、開始・中断・リセットで全員の画面が追従 |
| F5 | マス達成処理 | タップで達成トグル（写真提出なし） |
| F6 | ビンゴ判定 | ライン成立チェック、+5pt加算 |
| F7 | 追加ミッション | 送信（プールから選択、2回まで）、達成処理、重複マス自動開放 |
| F8 | 共通ミッション | 追加・編集・削除可能（全員可）、両チーム独立に達成可、達成ごとに固定2pt加算 |
| F9 | 面白出来事メモ | 自由テキスト投稿、得点化なし |
| F10 | タイマー制御 | 開始・一時停止・再開・6時間カウントダウン |
| F11 | 中断・結果発表 | 手動中断、結果発表ボタン、最終スコア・勝敗表示 |
| F12 | 完全リセット | confirm後、全データを初期状態に戻す |
| F13 | サーバー同期 | GAS(Google Apps Script)経由で4秒間隔ポーリング、全員の状態を共有 |
