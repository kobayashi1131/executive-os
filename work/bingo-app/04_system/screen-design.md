# 画面設計: bingo-app

`01_business/game-design.md` の仕様を元にした画面一覧・機能一覧。ラフモック段階のため詳細DB設計は行わない。

## 画面一覧・遷移

```text
S1 参加画面(名前・チーム選択)
  ↓
S2 項目プール管理画面(ミッション項目の追加・編集・削除)
  ↓
S3 カード作成画面(相手チームのカードを作る。項目選択＋配置)
  ↓
S4 待機画面(両チームのカード完成待ち／誰かが「開始」を押す)
  ↓
S5 プレイ画面(自チームのカード。タップして写真提出→達成)
  ├→ S5a 写真提出モーダル
  ├→ S5b 強制ミッション送信モーダル(項目プールから選択、残り回数表示)
  └→ S5c 受信した強制ミッション表示(通知バナー→カードに追加表示)
  ↓(時間切れ or 両チーム操作で終了)
S6 結果画面(最終スコア・勝敗・晩飯おごり演出)

常時表示: スコアボード(自チーム/相手チームの点数・残り時間)は S5 にヘッダー常設
```

## 画面ごとの内容

### S1 参加画面
- 表示: 名前入力、チーム選択（チームA/チームB）
- 操作: 参加登録

### S2 項目プール管理画面
- 表示: ファミリー別の項目一覧（易/普/難、カテゴリ、得点）
- 操作: 追加・編集・削除（全員が操作可能、権限制限なし）
- 初期データ: `game-design.md` のたたき台10ファミリー×3難易度を初期投入

### S3 カード作成画面
- 表示: 5×5グリッド（中央固定=パチンコ初当たり0pt）、項目プールから選ぶパネル
- 操作: 易8/普8/難8を選んでグリッドへドラッグ配置（自由配置）、自チームの相手（対戦相手）のカードを作る。作成中は自チームにも内容が見える
- 操作: 「ランダムで配置する」ボタンで、プールから各難易度8個を自動抽選し24マスにランダム配置（そこから個別に入れ替え可）
- バリデーション: 各難易度ちょうど8個埋まるまで「完成」にできない

### S4 待機画面
- 表示: 両チームのカード完成状況
- 操作: 誰か1人が「ゲーム開始」を押すと、両チーム同時に6時間タイマー起動

### S5 プレイ画面
- 表示: 自チームのカード（相手チームが作成）、各マスの状態（未着手/達成済み）、得点、残り時間、相手チームのスコア（リアルタイム）
- 操作: マスをタップ→写真提出モーダルへ
- ビンゴ成立時: 該当ラインをハイライトし+5pt加算

### S5a 写真提出モーダル
- 表示: カメラ起動 or 画像選択
- 操作: 提出＝即達成（相互承認なし）

### S5b 強制ミッション送信モーダル
- 表示: 項目プールから1つ選択、残り送信回数（2回まで）
- 操作: 送信→相手チームに通知
- 操作: プールに欲しい内容がなければ、その場で新規項目（内容・難易度・得点）を追加してすぐ選択できる（追加した項目はプール全体にも残る）

### S5c 強制ミッション受信表示
- 表示: 通知バナー、対象ミッションをカード外に表示
- 達成時: 写真提出→達成。ビンゴマスと同一項目なら対応マスも自動開放

### S6 結果画面
- 表示: 最終スコア、勝敗、達成ビンゴ数
- 未確認: 同点時の判定ルール

## 機能一覧

| 機能ID | 機能名 | 概要 |
|---|---|---|
| F1 | チーム参加 | 名前・チーム登録 |
| F2 | 項目プールCRUD | ミッション項目の追加・編集・削除（全員可） |
| F3 | カード作成 | 項目選択＋グリッド自由配置、完成判定 |
| F4 | タイマー管理 | 開始操作、6時間カウントダウン、終了判定 |
| F5 | マス達成処理 | 写真提出→即時達成、得点加算 |
| F6 | ビンゴ判定 | ライン成立チェック、+5pt加算 |
| F7 | 強制ミッション | 送信（プールから選択、2回まで）、受信通知、達成処理、重複マス自動開放 |
| F8 | スコア集計・共有 | リアルタイムで両チームに点数を公開 |
| F9 | 結果発表 | 最終スコア・勝敗表示 |
