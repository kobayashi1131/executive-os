# BCP 社員間の情報共有手順（A4・たたき台）

- 作成: 2026-10-14（小林の案をもとにIA子が整理）
- 状態: たたき台。2026-10-14 小林確認済み（開始の合図・分担・優先度・職人先・期限だけ伝える・記録表・定型文④）。社長・社員の確認前
- 想定: 担当者が急病・事故・災害などで急に動けなくなったとき、他の社員が仕事を引き継ぐための手順
- 印刷: 表面＝手順、裏面＝メール定型文

凡例: 【小林案】＝小林の考え／【採用】＝IA子の追加案を小林が採用／【未確認】＝採否未定

---

## 表面：担当者が動けなくなったときの手順

### 0. 始める合図【小林案】
- 次のどちらかになったら開始
  - 本人が病気・ケガなどで、自分で連絡できない
  - 本人と1週間連絡が取れない
- 引き継ぐ人：その場で社員が集まり、仕事ごとに分担を決める
- 分担は記録表に書き、社内で共有する（誰がどの仕事を見ているか分かるように）

### 1. 抱えている仕事を洗い出す【小林案】（優先度ABCは【採用】）
- 見る場所：案件管理アプリ／カレンダー／メール／LINE／机上・現場ファイル／引き継ぎシート
- 一覧にして、期限の近い順に並べる

| 優先 | 中身 | 例 |
|---|---|---|
| A 今日〜3日以内 | 施工日・搬入日が決まっている | 足場、職人の入り、材料の納品 |
| B 1〜2週間以内 | 打ち合わせ・見積の約束がある | 現調、見積提出日 |
| C それ以降 | 進行中だが急がない | 検討中の案件、アフター対応 |

### 2. 期限があるもの（A）は電話で連絡【小林案】（職人さんが先は【採用】）
- 相手：職人さん → お客様 の順（職人さんの段取りを先に止める／確定させる）
- 伝えること：①担当が不在になったこと ②予定どおりか延期か ③今後の窓口（代行者名・電話）
- 決められないことは「○日までに折り返します」と期限だけ伝える【採用】

### 3. 打ち合わせ・見積の確認（B）【小林案】
- 日時・場所・内容、見積の提出期限と進み具合を確認
- 見積の途中データ（職人見積・見積アプリ）の場所を確認
- 延期するもの／代行者が対応するもの を決める

### 4. 担当のお客様へメール（C含む全員）【小林案】
- 裏面の定型文を使う。電話済みのお客様にも、記録として送っておく

### 5. 連絡した記録を残す【採用】
- 「いつ・誰に・何を伝えたか・次の約束」を案件管理アプリ（または下の表）に残す
- 二重連絡・連絡漏れを防ぐため、社内で共有

| 日時 | 相手 | 伝えた内容 | 次の約束 | 連絡者 |
|---|---|---|---|---|
| | | | | |

### 6. 担当者が戻ったら【未確認】
- 記録を見ながら引き継ぎを戻す。お客様へ「本日から○○が戻りました」と一報

### 注意【未確認】
- 体調・ケガの詳しい内容はお客様に伝えない（「都合により」で十分）
- 約束できないこと（工期・金額）はその場で決めない。社長に確認してから回答
