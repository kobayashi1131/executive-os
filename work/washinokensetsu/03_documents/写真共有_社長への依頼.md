# 写真共有機能の実装に向けて(社長への依頼まとめ)

作成: 2026-09-29

## 1. 何が必要か(要点)

- 案件管理アプリの写真は今、アップロードした本人の端末にしか保存されておらず、他の人からは見えない
- 対策としてGoogle Drive経由で共有する仕組みを設計・検証済み(`work/washinokensetsu/04_system/docs/drive-photo-setup.md`)。テスト用の練習環境(`phototest2`)で「アップロード→保存→取得」が動くことは確認できている
- 残っているのは、**本物のGASコード・スプレッドシートに、この仕組みを安全に追加する作業**
- 安全に進めるため、本物とそっくりの「練習用コピー」を用意して、そこで先に試したい
- このコピーを作れるのは社長のGoogleアカウントだけなので、社長に次をお願いしたい:
  1. 案件管理用スプレッドシートのコピーを作る
  2. そのコピーに紐づくGoogle Apps Script(GAS)のコピーも作る
  3. 両方に小林を編集者として追加する

## 2. 社長のClaudeに渡す指示文

(そのままコピーして、社長がご自身のClaude(Claude.aiやClaude Code)に貼り付けて使う)

```
私は「わしの建設」の案件管理アプリの管理者です。今使っている案件管理用のGoogleスプレッドシートと、それに紐づくGoogle Apps Scriptのコピーを1つ作りたいです。目的は、小林さんが本物のデータに触れずに新機能(写真の共有機能)を試せるようにするためです。

次の手順を、私(パソコン操作に詳しくありません)が迷わないよう、1ステップずつ、次に何をクリックすればいいかだけを教える形で進めてください。一度に全部の説明をせず、私が「できた」と言うまで待ってから次に進めてください。

1. 案件管理用のスプレッドシートを開いて、コピーを作る(名前は「案件管理_練習用」などにする)
2. コピーしたスプレッドシートから、紐づいているGoogle Apps Scriptのコピーも作る
3. コピーしたスプレッドシートとApps Scriptの両方を、小林のGoogleアカウント(メールアドレスは私が伝えます)に編集者として共有する

進め方を1ステップずつ教えてください。
```

## 3. 社長向け説明文(なぜこれをお願いするか)

(そのまま口頭やメッセージで伝えられる、非技術的な説明)

> 前に相談してた、写真がアップロードした人にしか見えない問題、直す方法は見つかって、簡単な練習環境で「ちゃんと動く」ことまで確認できました。
>
> Dropboxは社長が気にしてたので使わず、今使ってるGoogle(スプレッドシートと同じ会社)の中にある「Googleドライブ」という保管庫を使う方式にしました。外部への公開リンクは一切作らず、常に合言葉つきの窓口を通してだけ写真をやり取りする設計です。
>
> ただ、本物のスプレッドシートやアプリの裏側の仕組みに直接手を加える前に、一回「本物そっくりの練習用コピー」を使って、既存の案件のデータや動きを壊さないか確認してから進めたいです。
>
> このコピーは社長のGoogleアカウントでしか作れないので、お手数ですがスプレッドシートとGoogle Apps Scriptのコピーを1つ作って、私を編集者に追加していただけますか?手順は上のClaudeへの指示文を使えば、Claudeが1ステップずつ案内してくれます。
>
> これができれば、本物のデータには一切触れずに安全に確認を進められます。
