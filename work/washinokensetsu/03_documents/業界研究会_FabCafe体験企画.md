# 業界研究会（FabCafe）体験企画案

- 作成日: 2026-10-20
- 対象: 大学1〜3年生
- 枠: 20分（会社説明5分／体験10分／訪問・インターン案内5分）

## 事実

- 事務局への回答（済み・想定）: 「①リフォームをお願いしたくなる会社の特長を考える」「②どんな時に建物を改造しようと考えますか？」の2点
- 事務局の他社事例は「自販機レイアウト」「アップサイズの声がけ」「冬に売れない商品を売る」など、答えが具体的な作業・ゲーム型

## 判断（課題）

- ①②はそのままだと「話し合いのお題」で、体験・ゲーム感が弱い
- 学生はリフォームを頼んだ経験がない → ①は「丁寧・安い・早い」に答えが収束しやすい
- 10分で2テーマは浅くなる → 1つのゲームの中で①②を両方回収する

## 提案: 「予算100万円 リフォーム会議」

回答済みの①②の枠内に収まるので、事務局への再連絡は不要（中身の進め方の工夫）。

### 進め方（10分）

| 時間 | 内容 | 回収するお題 |
|---|---|---|
| 1分 | 実例のビフォー写真＋お客さんカードを見せる（例: 70代夫婦、冬が寒い・段差でつまずく・トイレが和式・子ども世帯が帰省する） | ② どんな時に改造するか |
| 4分 | グループで工事カードから予算100万円以内で選ぶ | ② |
| 3分 | 2〜3グループに「何を選んだか・なぜか」を発表してもらう | ② |
| 2分 | 実際にお客さんが選んだ工事と理由を公開。「わしの建設は何を聞いて、どう提案したか」を解説 | ① 頼みたくなる会社の特長 |

### 工事カード例（金額は仮・要実例で調整）

| 工事 | 目安 |
|---|---|
| 手すり・段差解消 | 5万円 |
| 和式→洋式トイレ | 30万円 |
| 内窓（断熱） | 40万円 |
| 浴室リフォーム | 100万円 |
| 外壁塗装 | 120万円 |
| キッチン入替 | 80万円 |

### 締めのメッセージ（①の答え）

- 「全部やりたい」を予算内に絞るのがプロの仕事。お客さんの困りごとを聞き出して優先順位を一緒に決める会社が選ばれる
- 鉄骨・工場建設も同じ構造（お客さんの事業の困りごと→建物で解決）と一言つなげる

## 準備物

- 実例のビフォー/アフター写真（工程写真から1件選ぶ。施主の了承・個人情報が写らないもの）
- お客さんカード、工事カード（グループ数分）、予算シート
- 実際の採用工事と理由（2分で話せる量）

## 未確認

- 1グループの人数・グループ数、机の配置
- 使う実例1件の選定と金額の確定
- 事務局に送った回答が上記①②で確定しているか

## 再々修正: 「理由当て」をやめて3択・数字当てクイズに（2026-10-20）

- 事実: 工場を建てる・改修する理由は大体「手狭になった」で、当てっこにならない
- 判断: 理由ではなく「どう解決したか」「どれくらいの規模か」を当ててもらう。正解が実例の数字・選択なので、毎回答え合わせで「へぇ」が出る

### クイズ案（1問2〜3分、3問で約10分）

| 問 | 内容 | 回収するお題 |
|---|---|---|
| Q1 | 「工場が手狭になった会社、どうした？ A.隣に増築 B.建て替え C.別の土地に新築」→ 実例の選択と理由（例: 工場を止められないから等。実例で） | ② どんな時に建物を改造するか |
| Q2 | 「この骨組み（写真）、立ち上がるまで何日？」数字当て | 鉄骨の面白さ |
| Q3 | 「この柱1本、何kg？（軽自動車何台分？）」数字当て | 鉄骨の面白さ |
| 締め | 「お客さんに『わしのに頼んでよかった』と言われた理由」を紹介 | ① 頼みたくなる会社の特長 |

- 数字・選択はすべて実例から取る（作らない）
- 3人それぞれに答えを言ってもらい、一番近い人を「正解」にする（ゲーム性）

### 準備物（クイズ版）

- 工場の実例1〜2件: 「手狭→どう解決したか」とその理由、骨組みの工期、柱・梁の重さ、建方の写真
- お客さんから言われた褒め言葉・選ばれた理由（実際の声）
- 触れる実物（ボルト、鋼材の端材）、クイズを書いたボード、インターン案内

## 再修正: 「現場の判断を1つ体験」（2026-10-20）

- 小林の感想: クイズは就活生相手だと寒い
- 判断: 就活生が知りたいのは「この会社で働くと、どんな判断をするのか」。遊びではなく、実際にあった場面を1つ渡して「自分ならどうする？」を考えてもらう（ケース面接に近い大人向けの形）

### 流れ（約10分）

| 時間 | 内容 | 回収するお題 |
|---|---|---|
| 2分 | 実際にあった現場の場面を1つ説明（写真1枚） | - |
| 4分 | 「自分が担当ならどうする？」3人に聞き、理由を深掘り | - |
| 3分 | 実際にどう判断し、お客さんにどう伝え、どうなったか | ① 頼みたくなる会社の特長 |
| 1分 | 「こういう判断を毎日してる。続きはインターン/会社訪問で」 | 案内へつなぐ |

- 場面の条件: 正解が1つでない／お客さんの事情が絡む／若手でも考えられる
- 場面の例（形だけ。中身は実例で）: 工場を止められないお客さんの改修で工程をどう組んだか、天候で建方を延期するかの判断、予算内でお客さんの要望をどう削ったか
- ②（どんな時に建物を改造するか）は場面の背景説明で触れる

### 準備物

- 実際にあった判断場面1〜2件: 状況、選択肢、実際の判断と理由、結果（施主了承・特定されない範囲）
- 写真1枚ずつ、インターン案内のチラシ/QR

## 決定方向: 前回の「工程表マグネット並べ替え」を磨き直す（2026-10-20）

- 事実: 前回は工程のマグネットを最適な順に並べ替える体験を実施（例: クロスを貼る前にペンキを塗らないと汚れる）
- 判断: これまでの案（カード・写真クイズ・数字当て・判断ケース）より良い。手を動かす／正解に理由がある／実務そのもの／就活生に子どもっぽくない／ブース3人に合う
- 足すなら: 並べ終わった後に「お客さんの条件」を1つ追加して組み替えてもらう（例: 工場を止められない、この日までに使いたい）。①（頼みたくなる会社＝段取りの良さ）につながる

| 時間 | 内容 |
|---|---|
| 1分 | 改修の背景を一言（②どんな時に改造するか） |
| 4分 | マグネットを並べる |
| 3分 | 答え合わせ。「なぜこの順か」を現場の失敗談つきで |
| 2分 | 条件カードを1枚出して組み替え →「段取りでお客さんの損を防ぐのが仕事」で締め |

- マグネット・ボードが残っているか

## 最終方針: 社長案①②をそのまま活かす（2026-10-20）

- 事実: ①②は社長の案。工程表マグネットは前回実施済みで、社長はそれを知った上で別案を出している → 差し替えはしない（小林も無理に通さない）
- 判断: 課題は「①②を話し合いで終わらせない」こと。学生の答えと、実際のお客さんの答えの「ズレ」を見せる形にする（江崎商店の声がけ事例と同じ構造）

### 進め方（約10分）

| 時間 | 内容 |
|---|---|
| 4分 | ②「どんな時に建物を改造する？」学生に聞く →（実際）多いのは「手狭になった」＝会社が伸びて人や機械が増えた時。「建物の相談が来るのは、お客さんの会社が成長している時」 |
| 5分 | ①「どんな会社に頼みたい？」学生に聞く（安い・丁寧などが出る想定）→ 実際にお客さんがわしの建設を選んだ理由を見せ、ズレを解説 |
| 1分 | 「こういうお客さんと付き合う仕事。続きは会社訪問・インターンで」 |

- 「手狭」は退屈な答えではなく、「成長している会社と仕事をする」という前向きなメッセージにできる
- ①の答え合わせは必ず実際のお客さんの声を使う（作らない）

### 準備物

- 実際にお客さんから聞いた「選んだ理由」3つ程度（社長・現場から集める）
- 改修・増築の相談のきっかけの実例（手狭の中身: 人が増えた、機械を入れたい等）
- ボードかA4 1枚に「学生の答え」と「お客さんの答え」を並べて書ける欄
- 会社訪問・インターン案内

- 副次効果: 集めた「選ばれた理由」はそのまま営業資料・採用資料に使える

## 前提の追加: ①②は会社が本当に知りたいこと（2026-10-20）

- 事実: ①（頼みたくなる会社の特長）②（どんな時に建物を改造したいか）は、会社がお客さんに教えてほしいこと。答えは会社側も持っていない
- 判断: 答え合わせ型はやめる。「社長が本気で知りたい問いに、外の目線で意見をください」と正直に頼む形にする。中小企業は若手・外部の意見が経営に直接届く、という魅力そのものを体験してもらえる
- 注意: 学生は実際の顧客（工場を持つ会社）ではない。学生の意見は「外の目線のヒント」であり、顧客の本音の代わりにはならない。顧客への聞き取りは別途やる

### 進め方（約10分）

| 時間 | 内容 |
|---|---|
| 1分 | 「実はうちも答えを持っていない。お客さんに聞きたいことを、まずみんなに聞かせて」 |
| 4分 | ②「自分が会社の持ち主なら、どんな時に建物に手を入れる？」付箋に書いてボードに貼る |
| 4分 | ①「業者を探すなら、どう探してどこを見て決める？」付箋→ボード。前の組の付箋とも比べて話す |
| 1分 | 「集まった意見は会社で実際に使う。どう使ったかは会社訪問で見せる」 |

- ボードに付箋が1日かけて溜まっていくので、通りがかりの学生の足も止めやすい
- ①は学生のほうが強い領域（ネット・SNSでの探し方、Webサイトやインスタのどこを見るか）なので、実際の集客改善に使える

### 準備物

- ①②の2面ボード、付箋、ペン
- 冒頭の一言（正直に頼む）と、②を考えやすくする工場・建物の写真1〜2枚

- 別途: 実際のお客さんへの聞き取り（引き渡し時などに①②を聞く）

## 修正: 0から考えさせず「反応してもらう」（2026-10-20）

- 小林の懸念: 白紙の問いは0から生み出すことになり難しい。盛り上げる自信がない
- 判断: 人は0から考えるのは苦手だが、目の前のものに反応するのは得意。材料を渡して「選ぶ・ツッコむ」にする。盛り上げは不要で、少人数の会話として「意見をちゃんと聞いてもらえた」と感じてもらえれば成功

### ①: 自社のWebサイト・インスタを見てもらう（5分）

- スマホ/タブレットで実物を見せ「これ見て頼みたくなる？どこで見るのをやめた？」
- 補助: 「業者選びで見るもの」カード（価格／施工事例の写真／口コミ／担当者の顔・人柄／返信の速さ／近さ／資格・許可／インスタの雰囲気 等）から大事な順に3枚選ぶ。「ここにないものある？」は出ればラッキー程度

### ②: 状況カードで判断してもらう（4分）

- 「あなたが社長なら、建物に手を入れる？」カードを2〜3枚（例: 社員が倍になった／夏、工場が暑くて人が辞める／新しい機械が入らない／築30年で雨漏り）
- やる・やらない・様子見を選び、理由を聞く。判断の分かれ目が「僕たちの視点では気づけないこと」

- 社員が最初に自分の答えを1つ言う（呼び水）
- 前の組の選んだカード・付箋を見せて「前の人はこう言ってた、どう思う？」
- 黙っても気にしない。少人数の会話として、相手の意見をメモして聞く姿勢を見せる

### 準備物

- 自社サイト・インスタを開いた端末
- 「業者選びで見るもの」カード8枚程度、状況カード3〜4枚
- 意見メモ用紙（後で集計）、会社訪問・インターン案内

## 修正: 学生の「お客さん経験」から持ってきて建設に翻訳する（2026-10-20）

- 小林の懸念: 意見を聞くだけだと「早い・丁寧・安い」しか出ない。掃除・依頼のしやすさのような本当の差は働かないと分からないのでは
- 判断（一部同意・一部反対）:
  - 同意: 建設現場の中身は学生には分からない。直接聞けば三拍子で止まる
  - 反対: 掃除や依頼のしやすさは「働いて分かる」ことではなく「お客さんとして分かる」こと。学生も美容院・引っ越し・バイト先・ネット通販などでお客さん経験は豊富
  - → 建設について聞かず、自分のお客さん経験を聞いてから「建設会社なら何にあたる？」と翻訳してもらう

### 付箋2色の進め方（①・約5分）

1. 青の付箋: 「また頼みたい・また行きたいと思った店やサービス。決め手は？」（例: 予約がLINEで楽、終わった後きれい、説明が分かりやすい）
2. 黄の付箋: 「それ、建設会社だったら何にあたる？」
3. 三拍子が出たら: 「どこの会社も言ってる。じゃあ差が出るのはどこ？」と一歩だけ押す

### ②も同じ形（約4分）

1. 「自分の部屋・バイト先・部室を変えたいと思った瞬間は？」
2. 「それ、会社の建物だったら？」

### 期待値

- 学生の付箋は「外の目線のヒント」。①②の本当の答えは実際のお客さんに聞く（別途）

## 追加: 「自分ならどう改善する？」で締める（2026-10-20 小林案）

- 小林案: 翻訳の次に「お客さんが困らないように、自分ならどう改善する？」を聞く
- 判断: 賛成。分析で終わらず「提案する」まで行くので仕事体験になり、就活生向き。学生ならではの案（LINE・写真共有など）が出やすく、会社が知りたい「自分たちでは気づけないこと」に一番近い
- 条件: 困りごとは具体的に1つ渡す。「お客さんが困らないように」だけだと「もっと丁寧に」で止まる
- 困りごとは実際にあったもの・言われたものを使う（例の形: 工事中のほこり・音、進み具合が分からない、誰に連絡すればいいか分からない）

### 進め方（約10分）

| 時間 | 内容 | 付箋 |
|---|---|---|
| 1分 | 場面設定:「工場が手狭になって増築するお客さん」（②の答えの一例として示す） | - |
| 2分 | 「また頼みたいと思ったお店・サービスの決め手は？」 | 青 |
| 2分 | 「それ、建設会社だったら何にあたる？」 | 黄 |
| 4分 | 困りごとカードを1枚出し「自分ならどう改善する？」 | ピンク |
| 1分 | 「出た案は会社で検討する。結果は会社訪問で」 | - |

- 10分で①②を両方深くは無理。②は場面設定で触れる程度にし、①＋改善案に時間を使う
- ②をしっかり聞きたい場合は、青の問いを「自分の部屋・バイト先を変えたいと思った瞬間」に差し替える回を作る

---

## 整理版（2026-10-20 小林と合意した方向）

- ①の問い方: 「頼みたくなる会社の特長は？」→「頼みたくなる会社になるために、あなたならどうする？（わしの建設への提案）」
- ②の課題: 建設に関わっていない人は「建物を改造しよう」とは考えない（小林）。同意
- ②の解決: 学生を「建物の持ち主」ではなく「建物を使う人」として聞く。バイト先・学校で使いにくいと感じた場所なら誰でも答えられる。工場でも改修のきっかけは現場で働く人の不便から始まることが多い（仮説・要確認）

### 進め方（約10分）

| 時間 | 内容 | 付箋 |
|---|---|---|
| 1分 | 「今日はわしの建設に1つ提案してほしい。付箋1枚でいい」 | - |
| 3分 | ②ウォームアップ「バイト先や学校で、この建物使いにくいと思ったところは？」→「社長はそれに気づいてると思う？」 | 黄 |
| 5分 | ①本題「こういう不便を抱えた会社に、真っ先に頼まれる会社になるには？あなたならどうする？」 | ピンク |
| 1分 | 「提案は社長に届ける。どうなったかは会社訪問で」 | - |

- 流れ: 不便に気づく（②）→ 改修を考える → 誰に頼むか（①）が一本につながる
- ②の学生の答えはそのまま「お客さんの現場の不便」の例になる
