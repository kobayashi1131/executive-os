# 業界研究会（FabCafe）体験企画案

- 作成日: 2026-10-20
- 対象: 大学1〜3年生
- 枠: 20分（会社説明5分／体験10分／訪問・インターン案内5分）

## 事実

- 事務局への回答（済み・想定）: 「①リフォームをお願いしたくなる会社の特長を考える」「②どんな時に建物を改造しようと考えますか？」の2点
- 事務局の他社事例は「自販機レイアウト」「アップサイズの声がけ」「冬に売れない商品を売る」など、答えが具体的な作業・ゲーム型

## 判断（課題）

- ①②はそのままだと「話し合いのお題」で、体験・ゲーム感が弱い
- 学生はリフォームを頼んだ経験がない → ①は「丁寧・安い・早い」に答えが収束しやすい
- 10分で2テーマは浅くなる → 1つのゲームの中で①②を両方回収する

## 提案: 「予算100万円 リフォーム会議」

回答済みの①②の枠内に収まるので、事務局への再連絡は不要（中身の進め方の工夫）。

### 進め方（10分）

| 時間 | 内容 | 回収するお題 |
|---|---|---|
| 1分 | 実例のビフォー写真＋お客さんカードを見せる（例: 70代夫婦、冬が寒い・段差でつまずく・トイレが和式・子ども世帯が帰省する） | ② どんな時に改造するか |
| 4分 | グループで工事カードから予算100万円以内で選ぶ | ② |
| 3分 | 2〜3グループに「何を選んだか・なぜか」を発表してもらう | ② |
| 2分 | 実際にお客さんが選んだ工事と理由を公開。「わしの建設は何を聞いて、どう提案したか」を解説 | ① 頼みたくなる会社の特長 |

### 工事カード例（金額は仮・要実例で調整）

| 工事 | 目安 |
|---|---|
| 手すり・段差解消 | 5万円 |
| 和式→洋式トイレ | 30万円 |
| 内窓（断熱） | 40万円 |
| 浴室リフォーム | 100万円 |
| 外壁塗装 | 120万円 |
| キッチン入替 | 80万円 |

### 締めのメッセージ（①の答え）

- 「全部やりたい」を予算内に絞るのがプロの仕事。お客さんの困りごとを聞き出して優先順位を一緒に決める会社が選ばれる
- 鉄骨・工場建設も同じ構造（お客さんの事業の困りごと→建物で解決）と一言つなげる

## 準備物

- 実例のビフォー/アフター写真（工程写真から1件選ぶ。施主の了承・個人情報が写らないもの）
- お客さんカード、工事カード（グループ数分）、予算シート
- 実際の採用工事と理由（2分で話せる量）

## 未確認

- 1グループの人数・グループ数、机の配置
- 使う実例1件の選定と金額の確定
- 事務局に送った回答が上記①②で確定しているか

## 前提の修正（2026-10-20 小林より）

- FabCafeで行われる、同友会主催の企業説明会
- ブース形式。学生が話を聞きに来る。1グループ最大3人程度で、複数グループを同時に相手にはしない
- → 「グループ発表」「予算カードを複数班に配る」形式は不要。同じ流れを何回も回す前提にする

## 修正版: 写真クイズ＋実家ならどうする（約10分・1回転）

| 時間 | 内容 | 回収するお題 |
|---|---|---|
| 2分 | ビフォー写真を見せて「この家の人、なぜリフォームしたと思う？」 | ② |
| 2分 | 答え合わせ（本当のきっかけ）＋アフター写真 | ② |
| 3分 | 「自分の実家なら、どこ直したい？」3人に一言ずつ聞いて深掘り | ② を自分ごとに |
| 3分 | 「頼むならどんな会社がいい？」→ うちは困りごとを聞き出して優先順位を一緒に決めている、で締め | ① |

- 写真クイズは2〜3問用意し、学生の反応で入れ替える
- 任意: 触れる実物（ALC片、ボルト等）を置き、足を止めるきっかけにする（例: ALCは水に浮くと言われるので実物で要確認）

## 準備物（修正版）

- 施工例2〜3件のビフォー/アフター写真（施主了承・個人情報なし）、それぞれの本当のきっかけとエピソード
- ブース掲示用のビフォー/アフターパネル（通りがかりの目を止める用）
- 1回転の台本（誰が立っても同じ流れで回せる程度）
- 会社訪問・インターン案内のチラシかQRコード
- 任意: 触れる実物

## 再修正: BtoB前提（2026-10-20 小林より）

- 事実: 主力はBtoB（鉄骨・工場建設/改修）。住宅リフォーム寄りの「実家なら」は会社の実態とずれる
- 判断: 題材を「工場・倉庫」に変える。事務局回答の①②（リフォームを頼みたくなる会社／どんな時に建物を改造するか）は工場にもそのまま当てはまるので再連絡は不要

## BtoB版: 「この会社はなぜ工場を改修した？」（約10分・1回転）

| 時間 | 内容 | 回収するお題 |
|---|---|---|
| 1分 | 掴み: 「普段使ってる○○、どこかの工場で作られてる。その建物を建ててるのがうち」 | 身近さ |
| 3分 | 工場のビフォー写真を見せて「この会社、なぜ工場に手を入れたと思う？」 | ② |
| 2分 | 答え合わせ（実例の本当の理由）＋アフター写真 | ② |
| 4分 | 「工場を動かしながら工事するとしたら、何が困ると思う？」→ うちがどう段取りしたかで締め | ① |

- 想定される理由の例（学生の回答例。答え合わせは必ず実例で）: 手狭になった、新しい機械が入らない、夏が暑すぎて人が定着しない、耐震、雨漏り、動線が悪い
- 狙い: 建物の話が「会社の経営課題（増産・人手不足・安全）」につながるのを見せる。BtoBの面白さはここ

## 準備物（BtoB版）

- 工場・倉庫の施工例2〜3件: ビフォー/アフター写真、改修・建設の本当の理由、工事中に工夫した段取り（施主の了承必須、社名・製品を出せるかも確認）
- 掴み用: 施主が作っている身近な製品の例（出せる範囲で）
- 触れる実物: ボルト、鋼材の端材など
- 1回転の台本、会社訪問・インターン案内のチラシ/QR
